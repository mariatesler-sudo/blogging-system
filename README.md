Финальный проект — Платформа для ведения блога

Учебный финальный проект (11 класс)
**Тема:** платформа для ведения блога
**Автор:** Кубарова Мария
**Формат:** frontend + backend

Проект представляет собой веб-платформу для публикации постов, взаимодействия пользователей и управления контентом. Реализованы регистрация, авторизация, посты, комментарии, избранное, поиск, профиль пользователя, а также полноценный backend с тестированием и контейнеризацией.


 Выполненные критерии по ТЗ

### Фронтенд

*  Регистрация и аутентификация 
*  Страница профиля с редактированием 
*  Главная лента постов 
*  Страница создания поста 
*  Поиск постов 
*  Поиск пользователей 
*  Лайки и комментарии 
*  Возможность сохранять и просматривать избранные посты(и удалять из избранного)
*  Валидация форм 
*  Обработка серверных ошибок 
*  Unit и компонентные тесты (покрытие ≥ 50%) 



###  Бэкенд

*  Хранение данных в БД  
*  Контейнеризация (Docker) 
*  CRUD-операции для всех сущностей 
*  Валидация входных данных 
*  Авторизация и контроль доступа 
*  Пагинация и фильтрация 
*  Кэширование (Redis)
*  Unit + интеграционные тесты (покрытие **56%**)
